# Pet Assets

petdex 桌面宠物静态资源包，提供符合 petdex 精灵图规范的宠物素材。

## 素材列表

| 目录 | 名称 |
| ---- | ---- |
| `Qwen/` | 千问 |
| `gemini/` | Gemini |
| `glm/` | GLM |

## 目录结构

每套素材仅包含 petdex 最终产物：

```
<pet>/
└── final/
    ├── pet.json          # petdex 清单
    ├── spritesheet.webp  # 精灵图（petdex 使用）
    └── spritesheet.png   # 精灵图 PNG 版
```
